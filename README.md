# User Finder

## 概要
JSONPlaceholder APIからユーザー情報を取得し、検索した名前に該当するユーザーを表示するアプリです。

## 主な機能
ボタンを押すことでJSONPlaceholder APIから複数のユーザーデータを取得します。
名前を入力して検索ボタンを押すと、入力した名前を含むユーザーの情報を表示できます。

## 使用技術・API
- HTML
- JavaScript
- JSONPlaceholder API

## 学んだこと
- DOM操作を使って、取得したユーザー情報を画面に動的に表示する方法
- 関数の定義や呼び出し、引数、処理のまとまりについて理解が深まった
- 処理を関数に分けることで、コードの重複を減らし、後から修正しやすくできること
- APIを使ってデータを取得する方法と、取得したデータをアプリ内で活用する方法を学んだ
