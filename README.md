# User Finder

## 概要
JSONPlaceholder APIからユーザー情報を取得し、検索した名前に該当するユーザーを表示するアプリです。

## 主な機能
ボタンを押すことでJSONPlaceholder APIから複数のユーザーデータを取得します。
名前を入力して検索ボタンを押すと、入力した名前を含むユーザーの情報を表示できます。

## 使用技術・API
- HTML
- JavaScript
- JSONPlaceholder API
